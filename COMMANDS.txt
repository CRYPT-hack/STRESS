--- INSIDE THE BOT (type at the stress> prompt) -------------

/fcc                FCC mode: 4 challenges, HTML + JS tracks in parallel
/fcc 10             FCC mode: 10 challenges
/fcc js 6           JavaScript track only
/fcc html 3         HTML (Responsive Web Design) track only
/study              LeetCode learner agent (you press Submit)
/study 2            LeetCode, 2 problems
/teach              agent teaches what it learned
/quizme             agent quizzes YOU
/learner            progress: LeetCode + freeCodeCamp counts

/help               command list
/quit               leave (only after daily quota is met)
